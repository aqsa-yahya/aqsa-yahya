- Progress tracker and school portal on PostgreSQL with marks entry and performance reports.

**Tech:** Next.js 15, React 19, TypeScript, Tailwind CSS v4, PostgreSQL, Prisma, Gemini API

A full-stack real estate platform to browse, search and manage property listings.

- Secure authentication with NextAuth and MongoDB data models with Mongoose.
